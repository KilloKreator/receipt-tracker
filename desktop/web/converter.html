📘 Tutorial

Quick start: the whole job in 5 steps

  1. Download your transactions from Chase as a CSV file. How?
  2. In this program, pick the account (for example Chase Ink).
  3. Choose the CSV file you downloaded.
  4. Look over the list, then click ⬇ Download IIF file. More detail
  5. In QuickBooks, go to File → Utilities → Import → IIF Files and pick the file. More detail
💡 Always back up QuickBooks before importing: File → Back Up Company → Create Local Backup
🔒 This program never uses the internet. Your bank files stay on your computer.

Get the file from Chase

  1. Sign in at chase.com. Use a computer, not the phone app.
  2. Click the account you want (for example the Ink card).
  3. Above the list of transactions, click the download icon (a small arrow pointing down).
  4. For File type, choose Spreadsheet (Excel, CSV).
  5. Choose the dates you want, for example last month.
  6. Click Download. The file goes into your Downloads folder.
💡 Don't open the file in Excel and save it again before converting. Excel can change the dates and numbers.

Convert the file

Step 1: Choose the account. Pick it from the list. Each account remembers its own settings.

Step 2: Choose the bank's CSV file. Click the box and pick the file, or drag the file onto the box. If it's the wrong kind of file for that account, a red message tells you why.

Step 3: Check the list.

  • Include box ☑: ticked rows go into QuickBooks. Untick anything you don't want.
  • Type: Charge / Expense is money out. Credit / Deposit is money in.
  • Category: where the money goes in QuickBooks. Click in the box to type or pick a different one.
  • Payee: who you paid, e.g. Amazon.com. A rule fills it in, or you can type it. Otherwise it stays blank.
  • Customer: filled in automatically when a receipt scanned on the phone has the same amount and the same payee (closest date, within 30 days). A 🧾 shows it came from a receipt; hover over it to see which one. You can type or change it. It goes on the expense line in QuickBooks (the Customer:Job column), so the customer name must match QuickBooks exactly.
  • Memo: filled in automatically with the payee's name (e.g. Amazon). When the payee is blank, the memo holds the full bank description (e.g. Amazon.com*5E4250O42) so you can still tell what it was. You can type your own memo on any row.
  • + (far right, after Memo): makes a category rule from that row, so similar transactions get categorized automatically next time.
  • Auto-categorize ☑: on means use your rules. Off means everything goes to Uncategorized.
  • ⚙ Rules (next to Auto-categorize): category rules, your payee list, and each account's settings.
  • + next to a payee: add that payee, or set the words that auto-select it.

Check the totals above the list against your Chase statement. Then click ⬇ Download IIF file. The file is saved in your Downloads folder with a name like Chase-Ink_2026-11-01_to_2026-11-30.iif.

Want a spreadsheet too? Click 📊 Download Excel spreadsheet to save the ticked transactions as an Excel file (.xlsx) with totals at the bottom. Use it for your records, to review, or to send to your accountant. It is not for importing into QuickBooks, and it doesn't count as "already exported".

Import into QuickBooks Desktop 2021

  1. Back up first: File → Back Up Company → Create Local Backup
  2. Go to File → Utilities → Import → IIF Files
  3. If QuickBooks asks how to import, choose Import it for me. I'll fix it later.
  4. Find your Downloads folder, click the .iif file, and click Open.
  5. Wait for the message saying the import is done, then click OK.
  6. Check it: open Lists → Chart of Accounts (or press Ctrl+A) and double-click the account, for example Chase Ink. The new transactions are in the register.
💡 First time? Try a file with only a few transactions to check everything looks right.

Accounts

An "account" here is a bank account or credit card you bring into QuickBooks.

  • The program comes with three accounts ready: Chase Ink (credit card), Checking and Savings. If your QuickBooks uses different names (for example Chase Business Checking), click Edit account and change the name to match. Delete any you don't use.
  • + Add new account sets up a new one. Edit account changes the selected one.
  • QuickBooks account name: type it exactly as in QuickBooks (Lists → Chart of Accounts), including capital letters.
  • Account type:
    • Checking, Savings, Money Market, Cash / Petty Cash are all bank accounts in QuickBooks. Money in becomes a Deposit and money out becomes a Check (expense).
    • Credit Card: purchases become a Credit Card Charge and refunds become a Credit Card Credit.
  • Bank file format: pick Chase checking / savings or Chase credit card. For any other bank, pick Other bank. Then click Choose a sample CSV from this bank… and choose which column is the date, the description and the amount.
  • Uncategorized categories: where transactions go when no rule matches.
  • Delete account only removes it from this program. QuickBooks is not changed.

Rules: Category, Payees and Bank

Click ⚙ Rules in Step 3 (next to Auto-categorize). The window has three tabs:

📂 Category tab: which QuickBooks category

If Description contains "SHELL" → Category Automobile:Fuel
  • Type a short word that's always in the bank description. Capital letters don't matter.
  • Money can be In, Out, or In or out. A rule can apply to all accounts or just one.
  • If two rules match, the one higher in the list wins. Use ↑ ↓ to reorder them.
  • Quick way: click the + at the far right of a transaction.

🏪 Payees tab: who you paid

  • Your QuickBooks payee list (the master list, filled with 📋 Lists → Import), spelled exactly as in QuickBooks.
  • Add a payee: fill in "If the bank description says" (the words to look for) and "→ the payee is" (type or pick the payee). When a bank description contains one of those words, that payee is filled in. Example: The Home Depot with words HOME DEPOT, HOMEDEPOT.
  • Separate several words with commas. If several payees match, the longest matching word wins.
  • Also auto-select a payee when its name appears (ticked): even without words, LOWES #03444* → Lowes and SHELL OIL 57444 → Shell.
  • Quick way: click the small + next to a payee box in the transaction list. The bank description words are filled in for you; just type or pick the payee.
  • Tags in the list: new payee means it isn't on your list and will be created in QuickBooks when you import (only if Add new payees to QuickBooks automatically is ticked).
  • The memo is filled in with the payee's name. When no payee matches, the payee stays blank and the memo holds the full bank description.
  • When you add a payee (vendor) in QuickBooks, add it here too.

🏦 Bank tab: settings for each account

  • Where transactions go when no category rule matches (e.g. Uncategorized Expenses).
  • Skip card payments: on or off, so payments aren't counted twice.
⚠️ Category and payee names must match QuickBooks exactly. A category that doesn't exist can make the import fail.

Skipping card payments

When you pay your credit card bill, the payment is usually already entered in QuickBooks from your checking account. If you import it from the card too, it gets counted twice.

  • For credit cards, the Skip card payments box is on by default (in Edit account).
  • Skipped payments still show in the list, unticked, with a Skipped label.
  • To include one anyway, just tick its box.

Avoiding duplicates

The program remembers every transaction you've downloaded for each account.

  • If a later Chase file has dates that overlap, those transactions show as Already exported and are unticked, so only the new ones are imported.
  • If you downloaded an IIF file but never imported it into QuickBooks, tick those rows again.
  • To make it forget everything for an account: Edit account → Clear export history
💡 The program's memory only works on the same computer and browser. If you change computers, use Backup & Load settings.

Backup & sharing

Your accounts, rules and export history are saved by the program in Documents\KellerKraft Receipts, together with your receipts. Payees and customers are the master lists shared with the Receipts tab and the phone (📋 Lists at the top).

  • Everything is saved automatically by the program. To copy it to another computer, copy the Documents\KellerKraft Receipts folder.
  • ☰ → Load converter settings (top-right corner) brings in a backup from the old converter. It replaces the converter's accounts and rules and adds its payees.

Giving the program to someone else:

  1. Right-click this program's file and choose Send to → Compressed (zipped) folder (Windows). Some email services block un-zipped .html files.
  2. Email the zip file.
  3. They unzip it and double-click the file to open it in Chrome or Edge.
  4. Optional: send your settings backup file too, and they click Load settings.

Fixing problems

"This file doesn't match the column settings…"
You may have picked the wrong account in Step 1, or the bank changed its file. Check the account first. If it's right, go to Edit account → Column settings, click Choose a sample CSV… and pick the columns again.
QuickBooks created a new account I didn't want
A category name didn't match exactly. In Lists → Chart of Accounts, right-click the new account → Edit Account and rename it to the exact name of the right account. QuickBooks will offer to merge them. Then fix the rule in this program.
QuickBooks says a name is already in use
The payee name is already used by a customer, an employee or an other name. QuickBooks doesn't allow the same name twice. Either change the payee in the rule (e.g. Amazon.com - Vendor), or untick Add new payees to QuickBooks automatically to use the existing name.
I imported the same file twice
The simplest fix is to restore the backup you made: File → Open or Restore Company → Restore a backup copy. Or delete the extra transactions in the register (right-click → Delete).
QuickBooks says it needs single-user mode
Go to File → Switch to Single-user Mode and import again.
Nothing downloads when I click Download
Check your Downloads folder. The browser may also show a bar asking you to keep or allow the file.
My accounts and rules disappeared
This can happen after clearing browser data or using a different browser. Click Load settings and pick your backup file.
Some rows weren't read
A yellow message lists which lines and why (for example, a blank date). Check those lines in the CSV file.

Words to know

CSV file
A simple spreadsheet file. This is what Chase gives you.
IIF file
A file QuickBooks Desktop can import. This is what the program makes.
Register
The list of transactions for one account in QuickBooks, like a checkbook.
Chart of Accounts
QuickBooks' list of all accounts and categories. Lists → Chart of Accounts
Category
The QuickBooks account money is spent on or comes from (e.g. Office Supplies).
Rule
An instruction that picks a category automatically, based on words in the description.
Charge / Credit
On a credit card, a purchase / a refund.
Deposit / Check
In a bank account, money in / money out.
